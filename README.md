# NooRules Dev

Разработка, ревью, тестирование и выпуск.

## Установка в Codex

```sh
codex plugin marketplace add git@github.com:EgorPaleev/noo-dev.git
codex plugin add noorules@noorules-dev
```

Откройте целевой репозиторий и вызовите `$noo-setup`.

## Установка в Claude Code

```sh
claude plugin marketplace add git@github.com:EgorPaleev/noo-dev.git
claude plugin install noorules@noorules-dev --scope project
```

Откройте целевой репозиторий и вызовите `/noorules:noo-setup`.

## Работа в подключённом проекте

1. При подключении NooRules покажет загруженную версию плагина, точку входа и действующие правила проекта. Если чего-то важного не хватает, он предложит дополнение и внесёт его после согласования.
2. Откройте новую сессию в этом репозитории и отправьте задачу или ТЗ обычным сообщением. Можно явно вызвать рабочий навык, например `noo-review`. В обоих случаях агент учитывает инструкции и правила репозитория.
3. Агент покажет план и пайплайн вместе. Можно поправить объём, этапы, навыки или проверки. Если открытый вопрос меняет объём, агент сначала уточнит его.
4. Напишите «запускай», чтобы выполнить показанный вариант. Для справочного вопроса или запроса только на план агент вернёт запрошенный ответ сразу.

Для отдельного ревью достаточно diff. Отчёт проверок учитывается, если он есть. Для спецификации по согласованному кейсу прототип используется при наличии.

Агент соблюдает обязательные правила проекта и сам выбирает технический подход в согласованных границах. Для задачи без готового маршрута он собирает этапы по ТЗ и фактическому устройству проекта.

Навыки и материалы лежат в `plugins/noorules/` и готовы к установке из этого репозитория.
