# NooRules Dev

Разработка, ревью, тестирование и выпуск.

Установите пакет `noorules@noorules-dev` и откройте рабочую папку проекта. Вызовите `$noo-setup` в Codex или `/noorules:noo-setup` в Claude Code. Агент покажет загруженную версию, точку входа и действующие правила. После подключения откройте новую сессию в проекте.

Отправьте задачу или ТЗ обычным сообщением либо укажите рабочий навык. Агент учтёт правила проекта и предложит план и пайплайн в одном сообщении. При необходимости поправьте предложенный вариант и напишите «запускай».
