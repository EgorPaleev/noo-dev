# NooRules Dev

Разработка, ревью, тестирование и выпуск.

Установите пакет `noorules@noorules-dev` и откройте рабочую папку проекта. Для автоматического входа подключите проект через `$noo-setup`. Для явного вызова используйте `$noo-task`.

Для обычной задачи согласуйте подзадачи, посмотрите предложенный способ исполнения и дайте команду запуска. Точечный запрос с понятным результатом можно выполнить в одном ответе.
