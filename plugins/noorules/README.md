# NooRules Dev

Общие практики разработки, ревью, тестирования и выпуска. NooRules собирает сведения из файлов целевого репозитория и помогает оформить их в документацию и локальные правила, которые остаются в проекте.

Установите пакет `noorules@noorules-dev` и откройте рабочую папку проекта. Вызовите `$noo-setup` в Codex или `/noorules:noo-setup` в Claude Code. Агент покажет загруженную версию, точку входа и действующие правила. После подключения откройте новую сессию в проекте.

Отправьте задачу или ТЗ обычным сообщением либо укажите рабочий навык. Агент учтёт правила проекта и предложит план и пайплайн в одном сообщении. Дополнительные проверки для небольшой задачи можно выбрать здесь же. При необходимости поправьте предложенный вариант и напишите «запускай».

Агент показывает в чате текущую работу, переходы между этапами и результаты субагентов по мере готовности. Служебные файлы хранятся локально в `.noorules/runs/<id>/` и после завершения сокращаются до краткого итога. Если назначение ещё не согласовано, агент спросит, оставить ли изменения локально, отправить ветку или открыть PR.
