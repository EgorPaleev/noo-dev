# Прогресс приведения мобильного приложения к PWA

Дата: 19.11.2026. Ветка: `feat/pwa-design-parity`, ответвлена от `master` до изменений кода приложения.

Объём: дизайн и функциональность существующих экранов. Новые разделы не добавляются. Полная карта исходных расхождений — [pwa-parity-audit.md](pwa-parity-audit.md), запуск — [mobile-testing.md](mobile-testing.md).

## Готово в коде

### Общий UI и тема

- Manrope для заголовков, кнопок и цифр; Roboto для текста. Латиница, кириллица и цифры проверены в файлах шрифтов.
- Кнопки-пилюли, отдельные семантические цвета основного действия, нейтральное disabled-состояние, индикатор запроса и блокировка повторного нажатия во время запроса.
- Анимация нажатия и общий набор длительностей/кривой движения. Это ещё не полный перенос анимаций PWA.
- Светлая основная кнопка в тёмной теме приложения. Внутри саммита кнопка использует акцент организатора с выбором контрастного текста.
- Тема автоматически следует системной. Ручной переключатель и хранение выбора удалены по запросу.
- Платформенные эффекты синхронизируют системные панели с автоматической темой; iOS ещё не собрана и не проверена на устройстве.

### Вход

- Оба шага используют общую компоновку с логотипом, градиентным заголовком и доступной прокруткой при клавиатуре.
- Логотип использует цвет темы, тексты и интервалы приближены к PWA.
- Номер сохраняется через `rememberSaveable`; поле блокируется на время запроса, ошибка имеет зарезервированное место.
- «Продолжить» доступна после ввода десяти национальных цифр; окончательная проверка номера остаётся в существующей логике авторизации.
- Копирование номера подтверждения и открытие звонилки разделены. При копировании отображается галочка, звонилка открывается только действием «Позвонить».
- Отсчёт ожидания считается от срока сохранённой сессии; при возврате из фона пересчитывается по текущему времени.

### Главная саммита

- Нажатие карточки ближайшего события передаёт ID выбранной сессии в навигацию.
- Ошибка программы показывает сообщение с повтором загрузки. Если есть кэш, карточки остаются видимыми с сообщением об ошибке обновления.
- Исправлен контраст текста live-карточки в тёмной теме.

### Создание встречи

- Рабочее окно дня берётся из времени начала/окончания саммита, места — из точек площадки, когда навигация включена.
- Занятость пары участников загружается через `GET /api/summits/{id}/meetings/busy` с `participant_id`.
- Слоты строятся с шагом 30 минут в часовом поясе саммита; прошедшие и пересекающиеся интервалы недоступны. Длительность — 30–120 минут, не позже конца рабочего дня.
- Окончание в `24:00` преобразуется в полночь следующего дня.
- При смене участника время сбрасывается и запрашивается новое расписание. Ответ для прежнего участника не применяется к новому.
- Ошибка загрузки расписания блокирует отправку и даёт повтор. При наличии мест требуется выбрать существующую точку; её ID отправляется в API, название попадает в событие календаря.
- Перед отправкой актуальность слота пересчитывается по текущему времени и загруженной занятости; серверная проверка конфликтов остаётся окончательной. После ошибки создания занятость запрашивается снова.
- Исправлен разбор `retry_at: null` и RFC3339 для лимита повторных запросов. Описание ограничено 1000 символами.

### Иконки приложения

- Источник — текущая `public/icons/icon-512.png` PWA, светлый знак Sovpa на `#1b2129`.
- Android: legacy и round во всех существующих плотностях; adaptive foreground и monochrome переведены в вектор. Знак 42 dp в viewport 108 dp учитывает системную маску: итоговый размер около 58% видимой иконки.
- iOS: непрозрачный PNG 1024×1024, подготовленный из PNG PWA с масштабированием Lanczos.
- Изменены ресурсы иконок; публикация в сторы не выполнялась.

### Профиль, саммиты и нижняя навигация

- Профиль: имя и email редактируются отдельными листами, фото загружается сразу. Телефон меняется с подтверждением кодом. Удаление аккаунта перенесено в меню ⋮ с сохранением подтверждения.
- Частичный запрос профиля отправляет только изменяемое поле; пустой email передаётся явно для очистки.
- Исправлено прекращение наблюдения за пустым кешем профиля: загрузка/удаление аватара теперь обновляет действующие подписки, включая шапку саммитов и нижнее меню.
- «Мои саммиты»: группы текущих, предстоящих и прошедших по датам; раскрытие групп, страницы по 6 для предстоящих/прошедших, информационный лист для недоступного мероприятия.
- Нижнее меню содержит «Саммиты» и «Профиль». Повторный выбор не накапливает копии экранов. Контакты не добавлялись.
- Android dev временно использует `https://api.sovpa.ru`; iOS URL не изменён.

### Главная и профиль саммита: повторный проход по PWA

- Исправлена позиция карандаша ФИО; редакторы полей используют общий нижний лист с ручкой и крестиком. Удаление аккаунта остаётся в меню ⋮.
- История мероприятий перенесена с перехода на отдельный экран в нижний лист: все статусы, шесть строк на страницу, стабильная высота списка.
- Из шапки «Моих саммитов» убран профиль. Фото в нижнем меню берётся из общего кеша; его обновление проверено тестом непрерывной подписки.
- Карточки саммитов: акцентная кромка по закруглению, прогресс дней, логотип/цвет из API, отсчёт предстоящих и компактные даты. Окончание в полночь относится к предыдущему дню.
- В профиле приложения показаны текущие мероприятия с переходом внутрь, остальные доступны в истории.
- Главная саммита: приветствие с обработкой ФИО, даты в часовом поясе мероприятия; карусель текущей/следующей сессии и реальных счётчиков встреч; выключенные разделы скрываются. Добавлен `GET /api/summits/{id}/meetings/stats`. Сессии открывают программу.
- Меню аватара главной открывает профиль саммита, профиль приложения и выход с подтверждением. Перестроены плитки, карточки, отступы, типографика и последовательное появление блоков.
- Профиль саммита: бейдж, данные участника, должность/компания, теги с поиском, описание и дополнительные контакты редактируются отдельными листами. Настройки и QR тоже открываются листами; фото меняется через профиль приложения.
- Уведомления по разделам сохраняются локально на Android/iOS, как заглушка PWA. Публичность профиля сохраняется через существующий API с откатом при ошибке.
- Описание `bio` проходит DTO → entity → состояние → кеш. Схема Room 28 и миграция 27 → 28 сохраняют существующие строки; решение описано в [ADR 0009](adr/0009-summit-profile-bio-cache.md).
- Подтверждение копирования телефонов/email в обоих профилях зелёное.

## Проверка по присланным скриншотам и фильтры

- Исправлена общая причина светлых плашек: мягкий акцент смешивается с текущей поверхностью, а Material-компоненты получают палитру приложения. Это исправляет контраст меню и тёмные подложки новостей в чатах.
- Иконки разделов перенесены из тех же Phosphor regular definitions, что используются в PWA; MIT-лицензия упакована в ресурсы. Знак саммита использует скруглённую плитку, а не круг. Добавлены инициалы для аватара в шапке без фото.
- Поля главной и профиля саммита приведены к 24 dp по `SummitShellFrame`. Исправлено выравнивание заголовков секций, текста сессии и форм; осознанное центрирование шапок публичных профилей сохранено по PWA. Длинные имена и должности поддерживают бегущую строку.
- Кнопка QR в бейдже — 44 dp. Биография сворачивается до четырёх строк, если длиннее 280 символов; раскрывается по «Показать полностью» в своём профиле, профиле участника и спикера.
- По последнему запросу личные данные участника больше не редактируются в профиле саммита. Имя и фото ведут в профиль приложения; в редакторах саммита сохраняются должность, компания и профильные секции. Сетевой запрос этих редакторов исключает `full_name`, `phone`, `email`.
- «Участники»: серверные поиск и фильтр должности, API-варианты фильтра, страницы по пять как в BFF PWA, повтор после ошибки. Для поиска и фильтра используется `/profiles/recommended` с `search`, `position_id`, `page`, `per_page`.
- «Спикеры»: серверный поиск и фильтр темы `/speakers/filters`, страницы по шесть; фильтрация должности больше не используется активным экраном.
- В участниках, спикерах и программе фильтры открывают нижний лист с выбранным пунктом и сбросом «Все», как `FilterSelect` PWA.
- Программа показывает типы сессий из API, включая произвольные. Фильтр действует и во вкладке «Хочу посетить». Код и название типа сохраняются в Room-схеме 29, миграция 28 → 29 сохраняет существующие строки; см. [ADR 0010](adr/0010-program-type-cache.md).
- Процент мэтча программы открывает объяснение нижним листом прямо из списка. Есть загрузка, опрос pending, ошибка, повтор и отмена при закрытии. Объяснения на странице сессии и участника тоже открываются снизу.
- «Как добраться» открывает нижний лист с адресом из API и переходом в Яндекс Карты; исправлено UTF-8-кодирование кириллицы и специальных символов.

Последний расширенный прогон: 306 host-тестов в 11 модулях без ошибок и пропусков; отдельно прошли 13 тестов главной и Android devDebug. Проверены SQL миграций 27 → 28 → 29, соответствие колонок схемам Room, уникальность строковых ключей, валидность векторных XML и `git diff --check`. Новые зависимости не добавлялись. Визуальная проверка свежей сборки на устройстве и iOS-сборка остаются непроверенными.

## Меню аватара, звонок для смены телефона и исправление переходов

Ветка: `feat/pwa-design-parity`.

- Меню аватара главной собрано по PWA: радиус 20 dp, фото/инициалы, имя и телефон, разделители, Phosphor-иконки и выделенный выход из саммита. Ручной переключатель темы не возвращался.
- В профиле используются горизонтальные три точки. Действие удаления аккаунта оформлено закруглённой кнопкой с сохранением подтверждения.
- Оба доступных редактора телефона открывают подтверждение звонком. Запрос получает `call_phone`, `call_phone_pretty`, `expires_in`; подтверждение передаёт только `phone`, без SMS-кода. Есть таймер, повтор, отмена опроса при закрытии, звонок через `tel:` и копирование с зелёным подтверждением. Успешный ответ обновляет кеш основного профиля.
- Место сессии теперь передаётся в экран карты. Для старого кеша, содержащего название зала, первоначальная фокусировка умеет найти точку по имени и переключить этаж. Возврат сохраняет исходную страницу сессии.
- Кнопка участников сессии открывает нижний лист. Строки, заголовок, аватары 44 dp, кольца мэтча 36 dp и отступы сверены с `ProgramParticipantsDialog.tsx`. Высота списка ограничена 60% окна / 480 dp. Есть загрузка, ошибка/повтор, пустое состояние, страницы и переход в профиль.
- Общий поиск получил размеры и фокус PWA, очистку, клавиатурную команду поиска и задержку 350 мс. Карта использует тот же компонент; убрана дополнительная задержка во ViewModel участников.
- Этажи карты представлены отдельными чипами с промежутком и горизонтальной прокруткой.
- Масштабирование карты учитывает центр жеста и реальные границы схемы, в том числе поля вокруг широких/высоких карт. Кнопки масштаба используют тот же расчёт.
- Для каждого экрана Navigation3 задан непрозрачный фон и обрезка по границам; прямой, обратный и predictive-переходы используют согласованные настройки слоя. Исправление предназначено для устранения просвечивания предыдущей страницы при жестах; результат нужно проверить на устройстве.

Всего 260 тестов, без ошибок и пропусков. ## Общие нижние листы, новости, анимации и подключение

- Пункт удаления аккаунта стал компактным действием с иконкой, без красной подложки. Выбор источника фото использует общий нижний лист, обводки и акцентные иконки приложения; при загрузке на аватаре виден индикатор.
- Общий `NootinderSheet` повторяет структуру мобильного `SheetDialog` PWA: ручка, отдельный крестик сверху справа, заголовок 20/25 слева и пояснение 14/21. Подтверждения используют этот лист с основной кнопкой над отменой, высотой 44 dp и промежутком 10 dp. Выбор параметров встречи, создание диалога, селекторы профиля и информация о недоступном саммите тоже используют общий компонент. Тексты выхода из саммита синхронизированы с PWA.
- Общий поиск снимает фокус и скрывает клавиатуру при нажатии вне поля. Обработчик не поглощает событие: карточки, кнопки и другие поля продолжают обрабатывать это нажатие. Он работает в оболочке и нижних листах.
- Промежутки после поиска и фильтров участников и между блоками фильтров программы уменьшены до 8 dp.
- Новости сверены с `_pages/summit-chats/ui/NewsPage.tsx`: краткое пояснение под заголовком, без дополнительного блока с мегафоном; карточки с промежутком 10 dp, основным текстом 16/25.6 и отметкой «Новое». Акцентная полоса есть только у новых записей. Заглушки больше не содержат лишней шапки канала.
- Переходы Navigation3 получили короткое появление/исчезновение 160/120 мс при сохранении непрозрачных фонов и обрезки экранов. Карта приближается к выбранному залу и реагирует на +/− за 260 мс; ручной жест прерывает анимацию.
- На уровне приложения добавлен единый статус системного подключения. При потере сети показывается янтарное уведомление, при восстановлении — зелёное подтверждение. Ошибки загрузки отдельных экранов больше не определяют общий статус интернета.
- После offline → online активные экраны повторяют чтение через свои ViewModel. Для фона повтор откладывается до STARTED. Программа сохраняет выбор дня/вкладки/фильтра, чат — черновик сообщения. Редактор профиля с несохранёнными изменениями не перезагружается поверх черновика; формы и изменяющие запросы автоматически не отправляются. Открытые списки участников сессии и объяснения мэтча также повторяют загрузку.
- В списке чатов исправлена публикация промежуточного состояния: флаг загрузки и данные списка обновляются вместе. Тесты корректно завершают ViewModel до смены Main dispatcher.

Проверка: Android `assembleDevDebug` и host-тесты 21 затронутого модуля/оболочки, из них 18 имеют тесты. Всего 470 тестов без ошибок и пропусков; у FAQ, истории и карточки встречи пока нет host-тестов. Дополнительно прошли проверка 83 Compose XML, уникальность строковых ключей и `git diff --check`. Последние изменения повторно проверены сборкой APK и тестами главной, профиля саммита, сессии, профиля участника, программы и карты.

Системное подключение реализовано для Android и iOS, см. [ADR 0011](adr/0011-connectivity-recovery.md). iOS остаётся unverified: здесь Linux без Xcode. Переключения сети, поведение клавиатуры/жестов и визуальное совпадение свежего APK требуют проверки на устройствах.

Состав кеша, схема Room и правила его хранения в этом проходе не менялись. По просьбе пользователя подготовлено отдельное [предложение по кешу](cache-improvement-proposal.md); реализация этого предложения не начата.

## Профиль, справочники и единое обновление страницы

Дата: 2026-11-20. Ветка: `feat/pwa-design-parity`.

- Убрана повторная загрузка основного профиля при первом показе: исходные потоки уже загружают профиль и саммиты. Ручное обновление выполняет два чтения параллельно на IO, объединяет повторные нажатия и не удерживает выход из аккаунта за ожиданием сети. Секции профиля теперь создаются через LazyColumn по мере появления на экране.
- Редактор роли повторяет PWA: компания сверху, ниже подпись должности, поиск и отдельный ограниченный по высоте список. Повторное нажатие на выбранную должность снимает выбор; в запрос уходит nullable positionId.
- Сфера, запросы и компетенции используют такой же список: поиск, разделители, круглые индикаторы справа, выбранные на момент открытия первыми без перестановки после нажатия. Ограничение — восемь значений, есть счётчик; снятие выбора доступно при достигнутом лимите. Сохранение и отмена — кнопки общего дизайна высотой 44 dp.
- Общая навигация всех экранов использует появление со смещением вверх на 12 dp за 260 мс, в обе стороны. Сохранены непрозрачные фоны и обрезка, добавленные против наложения предыдущего экрана.
- «Текущий саммит» в основном профиле открывает сразу главную саммита, без SummitEntering. До перехода сохраняется выбранный id, а ViewModel главной получает ключ саммита, чтобы при смене контекста не использовать состояние другого мероприятия.
- Плашка отсутствия связи перенесена вниз, над нижним меню. В ней расположено единое действие «Обновить» с защитой от частых нажатий. Ручной запрос работает и offline, не меняя системный статус связи. Кнопки повторной загрузки на страницах заменены общей закруглённой кнопкой с текстом и иконкой; при offline они скрыты в пользу общей плашки. В открытых листах тот же элемент остаётся доступен, поскольку лист перекрывает основную страницу.

Проверены `assembleDevDebug`, host-тесты `core:presentation`, `feature-profile-impl`, `feature-summitProfile-impl`, `feature-main-screen-impl`, `shared`: 114 тестов без ошибок и пропусков. Прогон Gradle завершился с кодом 0. Проверены XML и уникальность ключей ресурсов, `git diff --check`. Состав и схема кеша не менялись.

Плавность профиля и переходов на устройстве не измерена: устранены обнаруженные повторные запросы и избыточное создание секций, но FPS/время кадра не замерялись. iOS остаётся unverified в Linux без Xcode.

## Стабильная загрузка списков, положение статуса связи и ошибки

Дата: 2026-11-20.

- Фильтры и поиск участников, спикеров и встреч больше не заменяются скелетоном при загрузке результатов. Плавная смена ограничена областью списка; высота области результатов зарезервирована, поэтому загрузка/пустое состояние не двигают управление. Список тем спикеров занимает постоянное место до прихода справочника.
- Индикатор фонового обновления программы отображается поверх области содержимого, не добавляя высоту над ней. Фильтрация программы и смена вкладок встреч используют короткое затухание результатов. Убрана автоматическая прокрутка к live-сессии после входа: текущая сессия задаёт начальный индекс списка сразу.
- Переключатель вкладок использует tween без отскока и не вызывает повторную загрузку при нажатии уже выбранной вкладки. Цвета чипов меняются за 150 мс; последовательное появление блоков сокращено до 260 мс с ограниченной задержкой.
- Профиль, программа и FAQ сохраняют ранее показанные данные в состоянии ViewModel при промежуточной загрузке и ошибке нового чтения. Успешный пустой ответ заменяет старый список; данные не маскируют ошибку, если экран ещё ничего не загружал. Хранение в Room и состав кеша не менялись.
- Плашка связи привязана к нижней navigationBars inset и фактически измеренной высоте нижнего меню, без фиксированного отступа 96 dp и двойного подъёма за счёт imePadding/safeDrawing. Изменение отступа и видимости плавное. В самой плашке осталась иконка обновления размером 44 dp, с доступным описанием для скринридера.
- Общий `NootinderLoadError` использует оформление ошибки карты площадки: круглая иконка, понятный заголовок и пояснение, единое действие обновления, размещение по центру доступной области. Он подключён к карте, новостям, основному профилю, участникам, спикерам и их профилям, программе, встречам, списку чатов, FAQ, истории, профилю саммита и списку саммитов. Ошибка обновления уже показанных данных не подменяет их полной страницей ошибки.
- В FAQ исправлена отдельная причина ложного «Ничего не нашли»: состояние ошибки загрузки теперь проверяется до отображения пустого поиска. Добавлены проверки первого сбоя, успешного пустого ответа, поиска без совпадений и сохранения списка после ошибки обновления.
- В тестах старых редакторов профиля добавлено завершение ViewModel перед сбросом Main dispatcher, чтобы фоновые корутины не переходили между тестами.

Проверки: `assembleDevDebug`; host-тесты `core:presentation`, `feature-profile-impl`, `feature-program-impl`, `feature-faq-impl`, `feature-meeting-impl`, `feature-ai-matching-participants-impl`, `feature-speakers-impl`, `feature-ai-matching-profile-impl`, `feature-speaker-profile-impl`, `feature-news-impl`, `feature-chats-list-impl`, `feature-summit-event-impl`, `feature-summitProfile-impl`, `feature-main-screen-impl`, `feature-summit-impl`, `feature-events-history-impl`, `shared`. Всего 397 тестов без ошибок и пропусков, Gradle exit code 0. Проверены XML, уникальность ключей строк и `git diff --check`.

Плавность и расположение на физическом устройстве ещё не проверены; время кадра/FPS не замерялись. iOS остаётся unverified в Linux без Xcode.
