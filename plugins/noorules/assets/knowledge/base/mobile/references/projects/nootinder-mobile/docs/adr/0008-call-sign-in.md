# 0008. Вход звонком через /api/auth/otp

## Status

Proposed

## Context

Экран входа просил код из SMS и подтверждал его через `POST /api/auth/otp/validate` с полем `code`.
Актуальный контракт auth на скриншотах другой: `POST /api/auth/otp` запускает проверку звонком и
возвращает номер, на который нужно позвонить, а `POST /api/auth/otp/validate` принимает только
телефон. Пока звонка нет, сервер отвечает `409 OTP_CALL_NOT_CONFIRMED`. Access token приходит в
JSON, refresh token — в HttpOnly cookie `refresh_token`.

Отдельных эндпоинтов SMS (`auth/sign-in`, `confirm`, `resend-code`) в этом контракте нет.

## Decision

- Номер на экране входа — национальный, только цифры. Перед запросом он проверяется
  libphonenumber (регион RU) и уходит в E.164. Пустой или невалидный номер не отправляется.
- Успешный `POST /api/auth/otp` сохраняет локальную сессию звонка: телефон пользователя,
  `call_phone`, `call_phone_pretty`, время старта и срок. Срок — `expires_in` ответа, но не
  дольше 15 минут. Просроченная сессия удаляется при чтении.
- Клиент опрашивает `POST /api/auth/otp/validate` с тем же телефоном каждые 5 секунд и ещё раз
  при возврате из фона. Повторные подтверждения идут через mutex. Любая ошибка, кроме отмены
  запроса, означает «звонка ещё нет»: токены и сессия остаются.
- Успех сохраняет access и refresh, сбрасывает кэш Bearer у Ktor, удаляет сессию звонка.
  Дальше приложение регистрирует push через уже существующий `PUT /api/push-devices` и открывает
  главный экран даже если push-токен получить не удалось.
- «Назад» и «Изменить номер» останавливают опрос и удаляют сессию. Живая сессия без токенов
  после перезапуска снова открывает экран звонка.
- Ошибка старта звонка остаётся на экране номера. На SMS-вход клиент не переключается.

## Consequences

- Экран кода из SMS остаётся в модуле, но из навигации входа больше не открывается.
- Смена телефона в профиле по-прежнему шлёт OTP с полем `code` на свои эндпоинты.
- Метаданные libphonenumber на Android читаются из assets и требуют application context до
  первой проверки номера.
