# ADR 0010: Типы программы из API в фильтрах и кеше

Статус: Proposed
Дата: 2026-11-19

## Контекст

Мобильный фильтр программы содержал только фиксированные «Доклады» и «Воркшопы», а API допускает другие типы с собственными кодом и названием. При сохранении программы в кеш исходный тип терялся.

## Решение

Сохранять `typeCode` и `typeLabel` сессии отдельно от прежнего признака оформления карточки. Фильтр строится из загруженных типов и применяется как к полной программе, так и к «Хочу посетить».

Room-схема 29 добавляет две nullable-колонки в `program_sessions_cache`. Миграция 28 → 29 использует `ALTER TABLE`, сохраняет существующие данные и включена в общую цепочку 27 → 28 → 29. Старые строки читаются с прежним кодом типа до обновления из API.

## Проверка

Тестируется круговой перенос произвольного типа через кеш. SQL миграции проверяется на существующих строках с сопоставлением колонок со схемой Room. Android собирается; iOS использует общий код, но не собрана в Linux.
