# ADR 0011: Общий статус подключения и обновление после восстановления сети

Статус: Proposed
Дата: 2026-11-19

## Контекст

Индикатор «Нет интернета» зависел от результата загрузки конкретного экрана. Из-за этого одна и та же потеря сети отображалась неодинаково, а ошибка API могла выглядеть как отсутствие интернета. После восстановления подключения требовался повтор вручную.

## Решение

На уровне оболочки приложения наблюдать за системным подключением: `ConnectivityManager` на Android, Network framework на iOS. Обработчики регистрируются один раз на время жизни оболочки и снимаются при её уничтожении. Android требует обычное разрешение `ACCESS_NETWORK_STATE`, без системного диалога.

Общий Compose-хост показывает компактное янтарное уведомление при отсутствии сети и зелёное подтверждение восстановления. Начальное состояние неизвестно до первого системного результата. На Android проверяется `NET_CAPABILITY_VALIDATED`; на iOS используется состояние доступного пути. Системная доступность подключения не гарантирует доступность конкретного API; серверные ошибки остаются ошибками экрана.

Счётчик восстановления увеличивается только при переходе offline → online. Активные экраны повторяют чтение данных через существующие ViewModel, не пересоздавая навигацию. Экраны в фоне ждут состояния lifecycle STARTED. Изменяющие запросы, например создание встречи, смена телефона или удаление аккаунта, автоматически не повторяются. Выбор дня, фильтры и черновик сообщения остаются во ViewModel.

Схема Room, состав сохраняемых данных, правила вытеснения и синхронизация отложенных изменений в этом решении не меняются.

## Проверка

Common-тесты проверяют первый результат наблюдения, повторные callbacks, потерю и восстановление подключения. Тесты программы и чата проверяют сохранение выбранных параметров и черновика при обновлении. Android собирается. Реальные переключения Wi-Fi/мобильной сети и iOS-сборка требуют отдельной проверки на устройствах.

Описание платформенного API: [Apple Network path monitor](https://developer.apple.com/documentation/network/nw_path_monitor_t).
