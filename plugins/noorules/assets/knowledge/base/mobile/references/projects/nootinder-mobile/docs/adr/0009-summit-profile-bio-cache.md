# ADR 0009: Хранение описания участника саммита

Статус: Proposed
Дата: 2026-11-19

## Контекст

Go API и PWA поддерживают поле `bio`, но мобильная доменная модель и кеш его не сохраняли. Редактор отдельных секций должен показывать актуальное описание и сохранять его при изменении других полей.

## Решение

Передавать `bio` через существующие DTO, доменную модель, состояние редактора и Room-кеш. Добавить nullable-колонку `bio` в `my_summit_profile_cache`, версию схемы 28 и общую миграцию 27 → 28 через `ALTER TABLE`. Существующие строки и другие таблицы сохраняются.

В запросе обновления описание передаётся явно, включая `null` для очистки. Редакторы секций используют текущий снимок профиля и существующий update use case. Лимиты тегов, контактов и описания соответствуют PWA и API.

## Проверка

Тестируется круговой перенос описания через кеш и сохранение при правке компании, а также очистка описания. Room генерирует схему 28 при Android-сборке. iOS использует ту же миграцию, но сборка iOS в Linux не проверена.
