# Проверки мобильной фичи

- [ ] Определены целевые платформы, устройство или симулятор и входные данные.
- [ ] Проверены основной сценарий, возврат, ошибки и пустые состояния.
- [ ] При изменении соответствующего поведения проверены потеря сети, восстановление и переход из внешней ссылки.
- [ ] Для каждого результата указаны версия сборки, платформа и окружение.
