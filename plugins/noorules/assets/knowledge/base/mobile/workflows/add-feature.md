# Добавление мобильной фичи

1. Уточни пользовательский сценарий, точки входа и целевые платформы.
2. Найди соседнюю фичу и определи, как проект разделяет общее поведение, платформенные интеграции и навигацию.
3. Подключи маршрутизацию, зависимости и ресурсы по местным соглашениям. Согласуй границы состояния и источники данных.
4. Проверь основной маршрут, возврат и затронутые состояния. Сверь команды сборки и проверок по целевым платформам с файлами проекта. Если команды или расположение тестов изменились, обнови их в канонической документации репозитория в рамках задачи.
