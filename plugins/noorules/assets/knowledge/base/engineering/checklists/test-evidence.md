# Подтверждение результата тестов

- [ ] Указаны изменённое поведение и покрытые критерии.
- [ ] Указаны фактически выполненная команда, версия и окружение.
- [ ] Для каждой проверки указан результат или причина пропуска.
- [ ] Ошибку можно воспроизвести по входам, шагам, фактическому и ожидаемому результату.
