# Проверка проектной документации

- [ ] Карта проекта даёт пути к точкам входа, модулям, контрактам и проверкам.
- [ ] У каждого технического факта есть проверяемый источник.
- [ ] Места, требующие уточнения, видны читателю.
- [ ] ADR описывает зафиксированное решение, его причину и последствия. Новая запись при пересмотре ссылается на предыдущую.
