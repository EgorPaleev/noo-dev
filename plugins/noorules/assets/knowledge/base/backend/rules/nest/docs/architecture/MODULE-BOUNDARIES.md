# Изоляция модулей

Модуль экспортирует (`exports: [...]`) только то, что реально нужно другим модулям — как правило, сервис. Импорт модуля не должен давать доступ к его внутренней реализации.

## Глобальные модули

`ConfigModule` и `CacheModule` подключены с `isGlobal: true` в `AppModule` — их не нужно импортировать в каждом модуле отдельно. Остальные модули (включая `PrismaModule`, помеченный `@Global()`) изолированы по умолчанию и импортируются явно там, где нужны.
