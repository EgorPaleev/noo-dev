# Константы

По умолчанию — `private readonly` поля прямо на классе, который их использует:

```ts
@Injectable()
export class ItemService
{
    private readonly CACHE_TTL_MS = 3600000;
}
```

В отдельный `constants/*.constants.ts` рядом с модулем константа выносится только тогда, когда она реально используется в нескольких файлах одного модуля (например, ключ очереди нужен и сервису, и процессору).
