# Проверка изменений Go

- Используй принятые в проекте команды для проверки форматирования, статического анализа, тестов и сборки.
- Для доменных изменений проверь инварианты, граничные значения и ошибки. Для HTTP проследи маршрут, валидацию, права, DTO и отображение ошибок до контракта.
- При изменении SQL проверь исходные запросы и повторяемость генерации. Для миграции используй изолированную тестовую базу и предусмотренный проектом сценарий перехода между версиями.
- Проверь, что запрос передаёт контекст в зависимости. Сравни итоговый diff с границами задачи и приложи фактические результаты.
