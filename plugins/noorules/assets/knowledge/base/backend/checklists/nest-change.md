# Ревью изменений NestJS

## Применимость

Изменение модуля NestJS, контроллера, сервиса, конфигурации или контракта.

## Проверки

- [ ] Ответственность контроллера, бизнес-логики и доступа к данным следует границам этого проекта.
- [ ] Декораторы, валидация и обработка ошибок соответствуют реальному контракту.
- [ ] Импорты, экспорты и зависимости модуля согласованы с соседними реализациями.
- [ ] Объявленные команды сверены с их содержимым. Команды, меняющие файлы, запускаются только в рамках поручения.
