## Статус материалов

Skills в этом комплекте восстановлены сейчас по материалам проекта для демонстрации. Они не являются историческими файлами и не установлены в NooRules или исходные репозитории.

Запрос клиента: «Сделать приложение для ИИ-нетворкинга на мероприятиях (саммитах и т. д.)». По рассказу владельца был отдельный файл клиентского ТЗ с функциональными пожеланиями; его содержимое не передаётся в этот комплект и не демонстрируется.

Исторические этапы, подтверждённые владельцем: проработка и согласование → КП отдельными промптами для презентаций и таблиц → демо → аналитика → прототип → декомпозиция и Битрикс → бэкенд с правилами и сбор мобильных правил с нуля → разработка и уточнение skills → веб и Telegram Mini App с частными skills → текущие ревью и тесты → будущий бэклог по тому же подходу. Это порядок рассказа, не доказанная временная последовательность коммитов. Текущие файлы — более поздний срез.

## Предметные различия

Общий план и подробные кейсы могут расходиться. Например, краткий план описывает вход по инвайт-коду, подробный кейс 1 — SMS; не разрешать расхождение без уточнения. Авторизация не используется как основной пример выступления.

В кейсе 7 есть % совпадения, объяснение взаимной пользы, темы для разговора, сообщение-ледокол и переходы к встрече и чату. Непубличный профиль имеет ограничения. В прототипе проценты и объяснения заданы вручную в participants-data.js, а не получены от модели. Не путать ИИ, которым создавали продукт, с демонстрацией ИИ-функции внутри продукта.

Нельзя утверждать наличие готового универсального mobile-skill или полностью автоматизированного КП. Web и Telegram Mini App подтверждены рассказом владельца; код этих реализаций в текущем комплекте не исследован.
