# Новый кейс Sovpa

Скилл лежит в репозитории фронта (`client-sovpa/.claude/skills/add-case`); в корне рабочей папки `sovpa`
на него символьная ссылка. Пути ниже — от корня `sovpa`.

Кейс — это данные в готовом шаблоне, а не новая вёрстка. Полная инструкция с полями, ограничениями
и командами: `client-sovpa/docs/workflows/adding-case.md`. Прочитать её целиком перед началом.
Образец: `client-sovpa/src/pages/cases/model/studies/cipr2026.ts`.

## 1. Разобрать материал

Из присланного (текст, PDF, ссылка, картинки) выписать только факты: событие и формат, задачу,
этапы, цифры, отзыв дословно, технологии, экраны. Ссылку открыть и забрать текст и изображения
контента. Если в материале нет:

- формата (`conference` / `corporate` / `industry` / `expo`) или
- хотя бы одной подтверждённой цифры или факта итога,

задать один вопрос пользователю. Остальное необязательное (плашка, экраны, сравнение, факты, отзыв)
просто не заполнять — блок не выведется. Ничего не придумывать: ни метрик, ни цитат, ни внешних ссылок.

## 2. Собрать кейс

1. slug (`/^[a-z0-9-]+$/`) и формат.
2. Картинки: обложка `public/cases/<slug>.webp` 480×480; экраны `public/cases/<slug>/*.webp`
   (`client-sovpa/.claude/skills/add-case/scripts/crop-screens.py` обрезает подложку и сохраняет webp до 1800 px).
3. `src/pages/cases/model/studies/<slug>.ts` по образцу ЦИПР, тексты в лимитах из доки
   (лид до 20 слов, этапов 2 или 4, факты до 3, неразрывный пробел в числах, без длинного тире).
4. Запись в `src/pages/cases/model/caseStudies.ts`.
5. Строка в `api-sovpa/prisma/seed.ts` → `realCases` (slug, format, title, meta, image, isFeatured),
   затем `docker/dctl.sh run npx prisma db seed`.
6. Тест страницы кейса в `src/pages/cases/ui/CasesPage.spec.tsx` по образцу ЦИПР.

## 3. Проверить

- Фронт: `npm run typecheck && npm run lint && npm run test && npm run build`.
- API (если менялся код): lint, `npx jest`, e2e через `docker/dctl.sh run`.
- `curl localhost:3000/v1/cases/<slug>` → 200, кейс есть в `?format=<format>`.
- Приёмка: `node client-sovpa/.claude/skills/add-case/scripts/shot.mjs` по страницам кейса, списка, решения формата
  (и главной, если `isFeatured`) на 1440×900 и 390×844 в обеих темах, посмотреть снимки.
  Пункты приёмки — раздел 7 доки.

## 4. Отчитаться

Ссылки на страницы, что взято из материала и что не заполнено (каких данных не было), результаты
проверок со счётом тестов, снимки. Коммит и пуш в `dev` — только по просьбе пользователя;
напомнить, что на сервере нужен `npx prisma db seed`.
