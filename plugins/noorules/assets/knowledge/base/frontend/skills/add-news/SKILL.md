# Новая новость Sovpa

Скилл лежит в репозитории фронта (`client-sovpa/.claude/skills/add-news`); в корне рабочей папки `sovpa`
на него символьная ссылка. Пути ниже — от корня `sovpa`.

Новость — это данные в готовом шаблоне, а не новая вёрстка. Полная инструкция с блоками, ограничениями и
командами: `client-sovpa/docs/workflows/adding-news.md`. Прочитать её целиком перед началом.
Образец: `client-sovpa/src/pages/news/model/posts/howSovpaStarted.ts`.

## 1. Разобрать материал

- Текст пользователя берётся дословно: разбить на 4–8 разделов с заголовками, заменить «—», поставить
  неразрывные пробелы в числах. Смысл не менять, своих фактов не добавлять.
- Если текст пишем сами — только подтверждённое (тексты продукта, кейсы, «О NooSoft»). Нет даты публикации
  или обложки — один вопрос пользователю.
- Между абзацами — блоки из доки (`facts`, `flow`, `comparison`, `features`, `screens`, `image`, `statement`, `link`)
  там, где они поясняют текст; не в каждом разделе и без повторов.

## 2. Собрать новость

1. slug (`/^[a-z0-9-]+$/`) и дата `publishedOn`.
2. Картинки: `python3 client-sovpa/.claude/skills/add-news/scripts/convert-images.py <исходники> client-sovpa/public/news/<slug>`.
   Повреждённые файлы скрипт пропускает — попросить прислать заново.
3. `src/pages/news/model/posts/<имя>.ts` по образцу, тип `NewsPost`.
4. Запись в `src/pages/news/model/newsPosts.ts`.
5. Строка в `api-sovpa/prisma/seed.ts` → `newsPosts` (slug, title и lead как на странице, image, publishedOn, `isInApp` — показывать ли новость в приложении;
   спросить пользователя, если не сказано), затем `docker/dctl.sh run npx prisma db seed`. Порядок выкладки: фронт, потом сид.

## 3. Проверить

- Фронт: `npm run typecheck && npm run lint && npm run test && npm run build`.
- API: `curl localhost:3000/v1/news/<slug>` → 200, новость находится поиском `?q=` по слову заголовка.
- Приёмка: `node client-sovpa/.claude/skills/add-case/scripts/shot.mjs` по `/news/<slug>/` и `/news/` на 1440×900 и
  390×844 в обеих темах, посмотреть снимки. Пункты — раздел 7 доки.

## 4. Отчитаться

Ссылки на страницы, что взято из материала и что изменено (разделы, типографика), какие картинки встали и какие
нет, результаты проверок со счётом тестов. Коммит и пуш в `dev` — только по просьбе пользователя; напомнить, что
на сервере нужен `npx prisma db seed`.
