# Проверка модального окна

## Проверки

- [ ] Владелец состояния выбран по действующим компонентам проекта.
- [ ] Открытие передаёт фокус, закрытие возвращает его в предсказуемое место.
- [ ] Закрытие, отмена и повторное открытие проверены на затронутых платформах.
- [ ] Ошибка отправки и долгий ответ сохраняют доступный путь выхода и повторной попытки.
