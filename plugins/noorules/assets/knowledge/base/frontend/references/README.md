# Общие frontend-правила

- [Качество кода](../rules/core/code-quality.md) и [чек-лист сдачи](../checklists/delivery.md) применяются по этапу задачи.
- [Правила React](../rules/stacks/react/component-conventions.md), [FSD](../rules/architecture/fsd/core.md) и остальные правила стека выбираются по профилю проекта.
- [Поиск инструкций](../workflows/rule-discovery.md) помогает на задачах, для которых подходящий сценарий ещё не определён.
