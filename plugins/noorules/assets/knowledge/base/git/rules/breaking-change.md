# Несовместимое изменение

Если сообщение следует Conventional Commits, обозначь несовместимое изменение знаком `!` непосредственно перед двоеточием заголовка или подвалом `BREAKING CHANGE: <описание>`. Опиши, что меняется для потребителя и какие действия нужны при переходе. Для ясности можно использовать оба обозначения.
