# Формат заголовка Conventional Commits

Если проект использует Conventional Commits, начинай сообщение с типа, затем указывай необязательную область в скобках, двоеточие, пробел и краткое описание. Для новой возможности используется `feat`, для исправления ошибки — `fix`. Дополнительные типы, наименование области и язык описания определяет проект.

```text
feat(search): add date filters
fix: обработать пустой результат
```
