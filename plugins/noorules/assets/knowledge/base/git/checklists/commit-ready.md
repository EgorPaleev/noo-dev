# Проверка готовности коммита

- [ ] Состав индекса соответствует выбранным изменениям.
- [ ] Случайные файлы, локальные настройки и секреты исключены.
- [ ] Проверки и их результаты зафиксированы.
- [ ] Сообщение соответствует проектной конвенции.
- [ ] После создания коммита проверены его содержимое и оставшиеся изменения.
