# Выбор состава коммита

1. Проверь состояние индекса и рабочей копии, включая новые файлы.
2. Выбери связанные изменения под одну задачу и перечисли файлы или фрагменты.
3. Проверь, что выбранные изменения включают нужные тесты и документацию. Оставь посторонние правки за пределами коммита.
4. Перед созданием коммита сравни подготовленное содержимое индекса с выбранным составом.
