# Правила подключённого проекта

Проект считается подключённым для текущего клиента, если его корневая точка входа (`AGENTS.md` в Codex, `CLAUDE.md` в Claude Code) загружает блок `<!-- noorules:task-entry -->`, который называет `noo-task`. Учитывай блок в общем файле, если клиент загружает его через корневые инструкции. В подключённом проекте обычный рабочий запрос или ТЗ поступает в `noo-task`.

Перед планированием и выполнением прочитай корневые инструкции, действующие инструкции затронутых каталогов и относящиеся к задаче документы проекта. Если существуют `.noorules/project.md` и `.noorules/profile.json`, используй их как указатели на источники, стек и проверки. Сверяй сведения с текущими файлами. Для каждого маршрута используй локальные материалы из `.noorules/local/tasks.json` по ключам маршрута и `*`. При расширении области или возобновлении этапа проверь правила затронутых каталогов снова.

Соблюдай обязательные требования репозитория в пределах их области действия. Используй рекомендации, примеры и материалы NooRules как опору для самостоятельного решения. Опирайся на код, данные задачи и доступные инструменты. Если правила проекта расходятся и область действия не разрешает конфликт, вынеси решение в план. Если подходящего правила или маршрута нет, продолжай по требованиям задачи и подтверждённым фактам проекта.

В ходе работы собирай подтверждённые сведения, которые пригодятся в следующей задаче. Сохраняй их в канонических документах этого репозитория, когда обновление документации входит в согласованный объём. Ссылайся на источники. Если обнаруженный пробел влияет на работу, предложи конкретную правку и путь для записи. Записывай новое правило команды или зависимость по согласованному поручению.

## Вызов рабочего навыка

- Если навык выполняет уже одобренную работу из `noo-task` или этап `noo-flow`, используй правила проекта и приступай по переданному контракту.
- Для нового рабочего запроса в подключённом проекте передай запрос в [`noo-task`](../../noo-task/SKILL.md) вместе с именем вызванного навыка. Если механизма передачи нет, прочитай инструкции `noo-task` и следуй им в текущем ходе. На этапе планирования используй инструкции навыка для определения входов, результата и проверки. Выполняй этап после запуска согласованного пайплайна.
- Для справки, рекомендации или запроса только на план либо спецификацию применяй правила проекта и возвращай запрошенный результат сразу. Вне подключённого проекта явный вызов работает напрямую с действующими правилами репозитория.
