# Подбор правил

1. В базе `../../assets/knowledge/` относительно этого навыка открывай `routes/<тип>.json` для известного маршрута. При неизвестном типе используй [карту задач](../../assets/knowledge/task-index.md). Если подходящего маршрута нет, подбери действующие правила проекта, общие локальные материалы и материалы по конкретному вопросу. Для точного ID открой только его запись в `lookup/<раздел>/<тип>.json`. При промахе проверь ID в [алиасах](../../assets/knowledge/aliases.json). Полный `index.json` нужен для точечного поиска метаданных, отсутствующих в остальных указателях.
2. Прочитай [правила проекта](references/project-context.md) и локальные материалы для выбранного типа задачи и `*`. Перед чтением материалов базы сверь `allPresets` и `anyPreset` по профилю и текущим файлам. К [каталогу пресетов](../../assets/knowledge/catalog.json) обращайся только за условиями, влияющими на текущий маршрут.
3. При планировании используй контракт маршрута и метаданные. Открывай содержание, если оно меняет объём, результат или способ проверки. При выполнении прочитай подходящие материалы `default`. Для `on-demand` проверь `when`, если задано, и открой материал, когда он нужен для конкретного решения или проверки. Используй один экземпляр каждого разрешённого пути и повторно обращайся к нему только при изменении файла или необходимости сверить деталь.
4. Сверяй шаблоны и рекомендации с актуальным кодом, правилами и версиями инструментов. Используй проектные факты из текущего репозитория. Если нужный документ отсутствует, помоги собрать его по файлам проекта и зафиксировать там же в рамках согласованной работы.
5. В режиме подбора верни подходящие ID с краткой причиной. При выполнении свяжи каждый применённый материал с решением, изменением или проверкой. Фиксируй как применённые только материалы, которые повлияли на работу.
