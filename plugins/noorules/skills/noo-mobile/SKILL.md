# Изменение мобильного приложения

Сначала [проверь подключение текущего проекта](../noo-rules/references/project-context.md#подключение-проекта). Выполняй этот навык NooRules Dev в подключённом проекте.

Для нового запроса используй [порядок входа рабочего навыка](../noo-rules/references/project-context.md#вызов-рабочего-навыка).

Возьми кейс и целевые платформы. Выбери через `noo-rules` один из типов: `mobile-feature`, `mobile-offline`, `mobile-deep-link`. Изучи реально используемые source sets, соседний модуль, навигацию и локальные команды проверок.

Выполни согласованный объём. Проверь затронутые платформы и сценарии. Укажи окружение и фактические результаты, отдельно отметь недоступные проверки. В пайплайне сохрани `change-set` с diff или ссылкой на его зафиксированную версию и укажи значимые новые файлы.
