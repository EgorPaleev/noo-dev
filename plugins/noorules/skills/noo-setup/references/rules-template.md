# Правила NooRules Dev для проекта

- Перед изменениями прочитай действующие инструкции и проверь Git-контекст. Используй правила проекта для базовой ветки, проверок, коммитов и выпуска.
- Предлагай план и проверки по задаче. Бери команды из существующих инструкций, манифестов или CI. Отмечай, какие проверки удалось провести.
- Используй раздел для исключений и правил, которые относятся к разработке в этом проекте.
