# Подключение NooRules

1. Найди корень проекта и прочитай действующие инструкции. Изучи манифесты, команды проверок и документы по задачам, для которых подключают NooRules. В монорепозитории выясни, какие соглашения принадлежат отдельным пакетам. Проверь [загруженный плагин и точку входа](references/project-layout.md#диагностика-подключения).
2. При первом подключении покажи инструкции, правила, навыки и команды, которые можно переиспользовать. При повторном запуске покажи изменения и оставшиеся пробелы. Для каждого существенного пробела предложи конкретное дополнение с путём и причиной. Если есть подходящий материал NooRules, объясни, где его взять. Записывай подтверждённые соглашения. Если для записи нужно решение команды, задай вопрос.
3. Подключи проект и внеси одобренные дополнения по [схеме проекта](references/project-layout.md). Переиспользуй канонические документы. Добавляй зависимости и внешние инструменты только по согласованному поручению. Сохрани уже действующие локальные настройки при повторном подключении.
4. Проверь, что каждый настроенный клиент видит один блок автоматического входа. В итоговом отчёте кратко укажи результат диагностики. На примере одной задачи покажи источник проектного правила, подходящий маршрут и доступную команду проверки. Дай ссылки на изменённые файлы. Если автоматический вход только что добавлен, предложи начать новую сессию в проекте и отправить задачу или ТЗ обычным сообщением.
