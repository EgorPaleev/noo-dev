# Подключение NooRules

1. Найди корень проекта и прочитай действующие инструкции. Если цель подключения ещё не ясна, спроси, для каких задач команде нужен NooRules. Изучи манифесты, команды проверок и документы только по этим задачам. В монорепозитории уточни, какие соглашения принадлежат отдельным пакетам.
2. Покажи найденные источники и настройки, которые влияют на работу. Уточни существенные пробелы, если ответ нельзя получить из файлов.
3. По запросу на подключение внеси согласованные настройки по [схеме проекта](references/project-layout.md). Используй канонические документы проекта. Создавай страницу, если она нужна для указанной цели и есть подтверждённый материал для её заполнения.
4. Для повторной настройки используй уже зафиксированные решения. Для Codex проверь, что корневой `AGENTS.md` содержит один блок автоматического входа. Покажи ссылки на изменённые файлы и проверь подбор правил для одной задачи репозитория.
