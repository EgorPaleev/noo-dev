# Реализация

Определи критерий ближайшего законченного изменения. Изучи владельца поведения, применимые инструкции репозитория и ближайшую проверенную реализацию. Для специфичной области используй `noo-rules` с точным типом задачи и открывай только релевантные модули.

Исполни согласованный объём, проверь поведение и diff. При необходимости используй `noo-test`. В пайплайне сохрани `change-set` с diff или ссылкой на зафиксированный diff, исходной точкой, связью с критериями и фактическими проверками. Укажи значимые новые файлы, которые обычный diff пропускает.
