# Работа с задачей

Если координатор передал тебе отдельный этап уже согласованного пайплайна, сразу выполни его по контракту и [правилам для субагента](../noo-flow/references/delegation.md). При отсутствии отдельного навыка-исполнителя используй материалы маршрута.

## Вход

- При явном вызове другого навыка используй его инструкции. На справочный вопрос отвечай прямо.
- Для нового сообщения без явного вызова применяй этот навык только если блок `<!-- noorules:task-entry -->` в корневом `AGENTS.md` текущего проекта называет `noo-task`. В остальных проектах обрабатывай обычные сообщения по правилам проекта. Явный вызов `noo-task` и продолжение уже начатого согласования работают без маркера.
- Если запрос явно ограничен самостоятельным действием с понятным результатом, выбери [навык по результату](../noo-guide/SKILL.md#навыки-по-результату), открой его файл `../<имя-навыка>/SKILL.md` и сразу выполни инструкции. Если запрос соответствует одному специализированному маршруту из базы направления, используй его контракт и материалы. Например, «подбери модель для ревью» означает рекомендацию по модели. Определи границу по смыслу. При отсутствии обязательного входа задай один конкретный вопрос. Верни результат навыка в запрошенном формате. Если в этом чате ждёт согласования другой план, сохрани его на текущем шаге.
- Если пользователь отвечает на ожидающее согласование, примени [правила согласования](../noo-flow/references/approval.md). Для запроса с несколькими связанными действиями или открытым объёмом предложи план работы. Обычный запрос на изменение кода проходит через план, даже если ожидаемый результат один.

## Работа по плану

1. Для новой задачи изучи относящиеся к ней файлы и результаты предыдущей работы. В кратком плане укажи необходимые подзадачи, существенные ограничения и способ проверить результат. Одного пункта достаточно, если работа проста. Уточняй только то, что меняет результат или границы. Если запрошен только план, дай план. Для рекомендации по пайплайну используй [правила подбора](../noo-flow/references/composition.md).
2. Когда объём принят, [подбери пайплайн](../noo-flow/references/composition.md) и сверь материалы через `noo-rules` в режиме планирования. Для простых связанных шагов предложи текущую модель и 0 субагентов. Покажи способ исполнения и дождись запуска по правилам согласования.
3. Передай согласованную работу в [noo-flow](../noo-flow/SKILL.md). Если механизма вызова нет, прочитай файл и выполни его инструкции в текущем ходе.
