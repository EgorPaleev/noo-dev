# Проверка и обновление NooRules

Запусти `python3 <путь-к-навыку-noo-task>/scripts/check_version.py --client codex` или укажи `--client claude` для Claude Code. Используй путь действительно загруженного навыка. Скрипт сравнит версию его манифеста с последним стабильным тегом по Git. Если вывода нет, продолжи работу. При недоступных инструментах или сети продолжи текущую задачу.

Если появилась новая версия, один раз покажи текущую и доступную версии и предложи обновить плагин. По просьбе «обнови плагин» выполни команды для установленного клиента из подключённого проекта, сохраняя выбранный источник установки.

- Codex CLI — `codex plugin marketplace upgrade noorules-dev`, затем `codex plugin add noorules@noorules-dev`.
- Claude Code — `claude plugin marketplace update noorules-dev`, затем `claude plugin update noorules@noorules-dev --scope project` для установки в проект. Для другой установки используй её действующий scope.
- В интерфейсе приложения кликни обновление у установленного плагина, если доступен соответствующий элемент. Если автоматическое выполнение недоступно, покажи пользователю подходящие шаги.

Для локального или закреплённого источника сохрани его и сообщи, как обновить соответствующую копию. После обновления сообщи результат команды и предложи открыть новую сессию, чтобы проверить загруженную версию. Текущую задачу останавливай только по просьбе пользователя.
