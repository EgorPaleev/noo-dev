# Выбор навыка NooRules

Если пользователь просит посоветовать пайплайн, [подбери цепочку по результату и имеющимся входам](../noo-flow/references/composition.md). Покажи подходящий сценарий или короткую последовательность этапов, назови материалы, которые можно переиспользовать, и дай пример вызова. Для выполнения предложи `noo-task`, а для названного сценария — `noo-flow`. Заверши ответ на рекомендации.

По результату, который нужен человеку, и уже доступным материалам предложи кратчайший маршрут. Для вопроса о направлении используй [карту направлений](../../assets/knowledge/directions.md). Для узкой задачи открой [карту типов](../../assets/knowledge/task-index.md). Запрос «какой навык выбрать» завершается рекомендацией.

## Навыки по результату

- Старт в репозитории — `noo-setup`.
- Неясное требование или термин — `noo-clarify`.
- Кликабельное демо — `noo-prototype`.
- Спецификация по готовому решению — `noo-spec`.
- Задача готова к реализации — `noo-implement`.
- Мобильный экран, офлайн-сценарий или переход по ссылке — `noo-mobile`.
- Запуск проверок — `noo-test`.
- Ревью изменений — `noo-review`.
- Оформление или подготовка коммита — `noo-git`.
- Выбор модели для задачи или нескольких шагов — `noo-model`.
- Несколько этапов с передачей файлов и возможностью продолжить — `noo-flow`.
- Для рекомендации отдельных инструкций используй `noo-rules`.
