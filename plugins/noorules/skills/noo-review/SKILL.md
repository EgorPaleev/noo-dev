# Ревью изменений

Сначала [проверь подключение текущего проекта](../noo-rules/references/project-context.md#подключение-проекта). Выполняй этот навык NooRules Dev в подключённом проекте.

Для нового запроса используй [порядок входа рабочего навыка](../noo-rules/references/project-context.md#вызов-рабочего-навыка).

Зафиксируй объект ревью и исходную точку сравнения. Прочитай diff, проверяемые требования и доступный отчёт проверок. Если отчёта нет, продолжи ревью и укажи, какие проверки не подтверждены. Используй `noo-rules` для `code-review`, а для затронутого контракта подключи подходящие правила стека.

Сначала перечисли подтверждённые замечания с приоритетом, местом, условием проявления и влиянием. Если замечаний нет, укажи остаточные риски и пропущенные проверки. По запросу только на ревью итогом служит отчёт. При вызове из пайплайна запиши его в предложенный файл `review-report`.
