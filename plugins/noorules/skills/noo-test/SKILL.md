# Проверка изменения

Начни с изменённого поведения и критериев из кейса, плана или diff. Подбери минимально достаточные проверки по файлам проекта. Сверь тело команд, чтобы распознать заглушки, watch-режим и автоисправления. Для ошибки фиксируй входы, шаги и наблюдаемый результат.

Зафиксируй фактически выполненные команды, окружение, результат и пропущенные части по [чек-листу](../../assets/knowledge/base/engineering/checklists/test-evidence.md). В пайплайне этот отчёт становится `verification-report`. Для платформенной задачи добавь только реально проверенные платформы.
