# Уточнение задачи

Сначала [проверь подключение текущего проекта](../noo-rules/references/project-context.md#подключение-проекта). Выполняй этот навык NooRules Dev в подключённом проекте.

Для нового запроса используй [порядок входа рабочего навыка](../noo-rules/references/project-context.md#вызов-рабочего-навыка).

Прочитай текущие требования, глоссарий и ADR затронутой области. Определи пользователя, ожидаемое изменение и проверяемый результат. Проверь по коду вопросы, которые можно решить исследованием репозитория. В разговор вынеси развилки, где выбор меняет объём, контракт или критерии.

Зафиксируй согласованный термин в действующем словаре. Существенное решение с реальными альтернативами запиши как ADR по [шаблону](../../assets/knowledge/base/engineering/templates/adr.md), если его подтверждённой записи ещё нет. Для открытого вопроса укажи влияние на работу. Если задача связана с одним модулем, связывай решение с его контекстом.

Для этапа `discovery` итог — бриф с границами и вопросами. Для `analysis` итог — функциональный кейс с основным сценарием, альтернативами и критериями. Если вызов сделан из пайплайна, сохрани итог в предложенный файл артефакта.
